# 🎮 Games Library (Laravel)

A modern Laravel-based web application for browsing and exploring video games. Users can view games by genre, check detailed game pages, and discover top-rated and latest games.

---

## 🚀 Features

- 🏠 Dynamic homepage with featured games
- 🎮 Browse games by genre
- 📄 Detailed game pages (title, image, platform, rating, genre)
- ⭐ Top-rated and latest games sections
- 🎨 Clean UI using Blade templates + Tailwind CSS
- 🗄️ Database-driven content using Laravel Eloquent

---

## 🛠️ Built With

- PHP
- Laravel Framework
- Blade Templating Engine
- MySQL
- Tailwind CSS

---

## 📂 Project Structure

- `app/Models` → Game & Genre models
- `app/Http/Controllers` → Game & Genre controllers
- `resources/views` → Blade views (pages + layout)
- `routes/web.php` → All application routes
